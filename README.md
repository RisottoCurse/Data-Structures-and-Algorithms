# Data Structures and Algorithms in C/C++

## Description

This repo will attempt to contain all key DSA utilised to make code more efficient and bridge the gap between theoritical and practical computer science. The code will be written in C/C++ with the possibily of it being adopted in more programming languages. 

It should be noted that although most programming languages do contain their own data structures users can implement, for example the STL in C++ and Collection Classes in Java, it is imper.. that we know how they work and how to efficiently use them. This repo should provide the code and examples to understand them thoroughly.

## Topics 

The topics covered are listed below

- Arrays
- Matrices
- Linked Lists
- Stack
- Queues
- Trees 
- Graphs
- Hashing 
- Recursion 
- Sorting
