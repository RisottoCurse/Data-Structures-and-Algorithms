# Two Pointers

## Definition

Two pointers is a technique that can be used on linear data structures such as arrays, strings and linked lists. It is useful as it can significantly improve time and space complexity from $O(n^2)$ to $O(n)$. There exist different types of two pointer techniques which will be explores in more detail below.
